# About this repo

This repo is my personal website, served by GitHub Pages at shamiecc.github.io.

## Tech rules

- Plain HTML, CSS, and minimal JavaScript only. No frameworks, no build tools, no generators.
- One shared stylesheet (styles.css) used by every page. Keep the CSS organized and commented.
- The site must work when served as static files from the repo root, so index.html lives at the root.
- Keep everything mobile-friendly.

## Writing and style rules

- Never use em dashes anywhere, not in visible text, not in comments. Use commas, colons, or parentheses instead.
- Plain, precise wording. No jargon, no metaphorical labels that could confuse a reader.
- Headings and titles in normal human formatting: capitalized words with spaces, like "Life Stories", never slug-style like "life-stories".
- Design goal: simple, classy, professional, unique. Generous white space, restrained color, nothing cluttered or flashy.

## Workflow rules

- I am learning as we build. After every change, briefly explain in plain language what you did and why.
- Make small, focused changes. Suggest a short, clear commit message after each meaningful change.
- Ask before adding anything I did not request.
